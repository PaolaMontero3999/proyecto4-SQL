# Proyecto 4: SQL

En este proyecto he realizado los cinco ejercicios obligatorios de consultas SQL utilizando PostgreSQL y pgAdmin.

La base de datos que he descargado desde el enlace del enunciado presenta algunas diferencias respecto a la versión utilizada en clase. Por ello, he tenido que adaptar algunos nombres de tablas y columnas.

En el ejercicio 4, la consulta se ejecuta correctamente, pero no devuelve resultados porque el modelo de avión con código 733 no está disponible en la versión descargada.
